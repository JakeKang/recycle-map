# 01. 시스템과 역할

## 서비스 개요

RecycleMap은 주변 수거함을 지도에서 찾고 시민 제보와 검증 의견을 누적하는 서비스입니다. 위치가 등록되었다는 사실과 위치 정보가 확정되었다는 사실을 구분합니다. 따라서 목록과 상세에서 항상 `확인 중`, `확정`, `정확하지 않음` 상태를 먼저 확인합니다.

## 역할

| 역할 | 가능한 작업 |
| --- | --- |
| 방문자 | 지도 이동, 검색·분류, 위치 상세·검증 집계·리뷰 열람 |
| 로그인 사용자 | 방문자 기능 + 위치 등록, 타인 제보 검증 투표, 리뷰, 신고, 수정 제안 |
| 제보 작성자 | 로그인 사용자 기능 + 자신의 제보 수정. 자신의 제보에는 투표 불가 |
| 관리자 | 로그인 사용자 기능 + 검증 상태 수동 조정, 신고 해결·기각, 수정 제안 적용·기각 |

## 상태 용어

- `확인 중`: 아직 자동 확정 또는 오류 기준에 도달하지 않은 제보입니다.
- `확정`: 정확 투표가 5표 이상이고 전체 투표 중 정확 비율이 70% 이상인 위치입니다.
- `정확하지 않음`: 잘못 투표가 3표 이상인 위치입니다. 이용 전에 현장을 다시 확인해야 합니다.
- `관리자 조정`: 운영자가 검증 상태를 직접 지정한 상태입니다. 상세 화면에 조정 사실이 표시됩니다.

## 기본 이동 방식

- 데스크톱: 왼쪽 탐색 레일, 가운데 지도, 오른쪽 상세·검증 원장을 함께 사용합니다.
- 모바일: 지도를 중심으로 상단 메뉴와 하단 탭을 사용합니다. 위치 선택 시 상세 시트를 위아래로 끌어 `미리보기`, `중간`, `전체` 높이로 바꿀 수 있습니다.
- 브라우저 뒤로가기는 검색, 분류, 선택 위치, 열린 시트의 URL 상태를 따라 이전 작업면으로 복원합니다.

## 개인정보와 안전

위치 제보에는 개인 연락처나 주거 출입 비밀번호를 입력하지 않습니다. 잘못되었거나 사라진 위치는 검증 투표와 별도로 `문제 신고`를 사용해 운영자 검토를 요청합니다.
